# ElevenLabs AI Voice Agent 🎙️

A deployed conversational AI agent built using ElevenLabs' 
Agents platform with a custom knowledge base and RAG enabled.

## What This Does
- Answers questions using a custom knowledge base
- Uses RAG (Retrieval Augmented Generation) to retrieve 
  accurate answers from uploaded documents
- Responds in natural voice using ElevenLabs voice synthesis

## How It Was Built
- Platform: ElevenLabs Agents dashboard
- LLM: Gemini 2.5 Flash
- Voice: Monika Sogam
- Knowledge Base: Custom content with RAG enabled

## Key Concepts Demonstrated
- Conversational AI agent configuration
- Knowledge base setup and document ingestion
- RAG implementation for accurate responses
- Voice AI deployment and embedding

## How to Run
Paste the embed.html snippet into any webpage to 
interact with the live agent.
